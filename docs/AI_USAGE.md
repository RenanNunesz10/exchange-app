# Registro de Uso de IA (`AI_USAGE.md`)

Este documento descreve de forma geral como ferramentas de Inteligência Artificial foram consultadas durante o desenvolvimento do projeto **Currency Exchange App**.

---

## 1. Ferramentas Consultadas
- Assistentes de IA generativa (como ChatGPT / Claude) utilizados como apoio para tira-dúvidas e consultas pontuais.

---

## 2. Finalidade de Uso
A IA foi utilizada de forma pontual e consultiva, servindo como apoio para:

- **Consulta de sintaxe e documentação:** Esclarecimento de dúvidas sobre a integração de bibliotecas (como Recharts para gráficos) e sintaxe de CSS Modules.
- **Estruturação de documentação:** Apoio na organização inicial dos templates de documentação em Markdown (`REQUIREMENTS.md`, `COMPONENTS.md`, etc.).
- **Tira-dúvidas de JavaScript:** Consulta de métodos nativos para manipulação e ordenação de arrays e formatação de datas.

---

## 3. Considerações Finais
Toda a lógica de negócio, arquitetura dos componentes React, gerenciamento de estado (`useState`, `useEffect`, custom hooks), consumo da API Frankfurter e validação dos dados foram desenvolvidos, testados e adaptados diretamente pelo autor do projeto.
